# Browsing & Searching

## Browse by Folder

The catalog is organized into **four main folders**, matching how items are stored in the factory:

1. **ACCESSORIES** — Buttons, zippers, rivets, buckles, eyelets, hooks, needles, tapes, studs, and special items
2. **HANGTAGS & PACKAGING** — Branded hang tags (per customer), polybags, packing materials
3. **LABELS & TAGS** — MARDI branded labels, size labels, tags
4. **LINING & INTERLINING** — Satin lining fabrics in various colours

Click a folder to filter the catalog to only items in that folder.

## Browse by Category

Within each folder, items are grouped into categories. The **category sidebar** on the left shows all categories with item counts.

### Categories with Subcategories

Some categories expand to show subcategories:

| Category | Subcategories |
|----------|---------------|
| **Buttons** | Hard Buttons, 4-Part Buttons, Branded Buttons, Button Parts & Covers, Jeans Buttons |
| **Zippers** | Zippers - YKK, Zippers - Non-YKK |
| **Rivets** | Black, Crystal Nug Rivet, Golden, Gun Metal, Matt Silver, Silver Shine |
| **Eyelet** | Black, Golden Shine, Matt Silver |
| **Branded** | One subcategory per customer (Karen Millen, ALE, MARDI, etc.) |

Click a subcategory to filter items within that specific group.

## Search

Type in the search bar to find items by name. The search filters as you type.

**Search tips:**
- Search by colour: "gun metal", "matt silver"
- Search by size: "15mm", "#5"
- Search by type: "roller buckle", "flat rivet"
- Search by brand: "YKK", "karen millen"

## Item Codes

Every item has two identifying codes:

- **Sortly SID** — The original code from Sortly (e.g., `SLUEDT0156`). Used during the transition period.
- **Part #** — Internal code auto-generated by the system (e.g., `BTN-0001`, `ZIP-0042`). This is the permanent reference code.

Both codes appear on the item detail page and can be copied to clipboard.

## Sorting

Items can be sorted by:
- **Name** (A-Z)
- **Price** (low to high, or high to low)
- **Stock** (low to high, or high to low)
- **Last updated**
